# 크몽(Kmong) 등록 가이드 — Claude Code 실전 완전정복

아래 내용을 크몽 "서비스 등록" 폼에 그대로 옮기면 됩니다.
(크몽 로그인 → 전문가 인증/프로필 등록 → 판매 관리 → 내 서비스 → 판매 시작하기)

> ⚠️ **먼저 확인하세요**: 크몽은 서비스 등록 전 "전문가 인증"(본인인증)이 필요합니다.
> 보통 한국 통신사 휴대폰 인증 기준이라, 외국인의 경우 대체 인증(외국인등록증 등) 지원
> 여부를 [크몽 고객센터](https://support.kmong.com)에 가입 전 문의를 권장합니다.

```

서브에이전트, 훅, MCP까지 — 실제 작동하는 설정팩(커맨드 35종·에이전트 11종·훅 15종)과
함께 배우는 한국어 실전 가이드입니다.
```

## 4. 상세 설명 (본문)

```
Claude Code 잘 쓰고 계신가요, 아니면 그냥 채팅하듯 쓰고 계신가요?

설치법을 알려주는 자료는 많습니다. 하지만 CLAUDE.md를 어떻게 설계하는지,
반복 작업을 커스텀 커맨드로 어떻게 압축하는지, 서브에이전트에게 왜 Write 권한을
주면 안 되는지, 훅으로 어떻게 "사고가 구조적으로 불가능한" 환경을 만드는지 —
여기까지 다루는 한국어 자료는 드뭅니다.

📌 이런 분께 추천합니다
- Claude Code를 써봤지만 "좋은 채팅" 수준으로만 쓰고 있는 개발자
- 바이브코딩으로 시작했는데 프로젝트가 커지며 한계를 느끼는 분
- 팀에 AI 코딩 도구를 도입하려는 리드/시니어

📘 목차 (PDF 본문)
1장. 설치와 첫 실행 — 5분 안에 끝내기
2장. CLAUDE.md — 프로젝트의 기억을 설계한다
3장. settings.json — 권한과 환경을 통제한다
4장. 커스텀 슬래시 커맨드 — 반복 작업을 명령어로
5장. 서브에이전트 — 역할별 전문가를 고용한다
6장. 훅(Hooks) — 사람이 안 지켜봐도 되는 가드레일
7장. MCP 서버 — Claude의 손을 외부로 확장한다
8장. 실전 워크플로우 4종 (신규 기능·버그픽스·보안감사·병렬 리팩토링)
9장. 컨텍스트와 비용 관리
10장. 트러블슈팅 FAQ
부록. 설정팩 설치·커스터마이징 가이드

✅ 이 상품의 차별점
- 모든 예제가 실제로 작동하는 설정 파일입니다. "이런 게 가능하다"가 아니라
  파일 경로, JSON 키, 스크립트 내용까지 그대로 따라 할 수 있습니다.
- 커스텀 커맨드 35종, 서브에이전트 11종, 자동화 훅 15종, 규칙 파일 8종이 담긴
  설정팩(zip)을 함께 드립니다. 설치 스크립트 포함 — 받아서 바로 쓰세요.
- 각 장마다 절차 다이어그램이 있어 그림만 봐도 순서를 따라갈 수 있습니다.

🎁 패키지 구성
- 전자책 PDF (전 패키지 공통)
- 치트시트 2페이지: 슬래시커맨드·단축키·설정 템플릿 요약 (전 패키지 공통)
- 설정팩 zip: 커맨드·에이전트·훅·규칙 + 설치 스크립트 (DELUXE 이상)

📄 형식: PDF (한국어) + zip, 즉시 다운로드
⏱ 발송: 결제 확인 후 1일 이내 크몽 메시지로 전달

※ 투명성 고지: 동봉 설정팩은 MIT 라이선스 오픈소스입니다. 구매하시는 것은
설정팩 자체가 아니라, 그것을 이해하고 내 프로젝트에 맞게 활용하는 방법을 담은
한국어 가이드북 + 치트시트 + 큐레이션입니다.
```

## 9. FAQ (등록 화면의 "자주 묻는 질문" 섹션용)

```
Q. 개발을 잘 몰라도 따라 할 수 있나요?
A. 터미널을 열어본 적이 있는 분이라면 1장부터 순서대로 따라 할 수 있게 썼습니다.
   다만 완전 비개발자보다는 코딩 경험이 조금이라도 있는 분께 적합합니다.

Q. 설정팩은 어떤 환경에서 동작하나요?
A. macOS / Linux / WSL 기준입니다. Windows 네이티브도 대부분 동작하지만
   설치 스크립트는 PowerShell 버전을 사용합니다.

Q. Claude 유료 구독이 필요한가요?
A. Claude Code 자체는 Claude Pro/Max 구독 또는 API 키가 필요합니다.
   이 책은 그 비용을 최대한 효율적으로 쓰는 법(9장)도 다룹니다.

Q. 업데이트 되나요?
A. Claude Code 기능 변경으로 내용이 크게 달라지면 개정판을 제작할 예정이며,
   구매자에게는 크몽 메시지로 안내드립니다.
```
