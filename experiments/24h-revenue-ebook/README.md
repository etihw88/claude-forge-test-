# 24시간 수익화 실험: AI 부수입 전자책

"24시간 안에 돈을 벌어와라"는 실험 미션에서 출발한 결과물입니다. 실제 결제/입금까지는
자동으로 처리할 수 없어(계좌·사업자 정보가 필요), **24시간 안에 판매 개시가 가능한
상태**로 결과물을 준비하는 것을 목표로 삼았습니다.

## 무엇을 만들었나

주제: "AI로 부업/수익화하기" — 이 repo(claude-forge, Claude Code 프레임워크)와 맞닿아
있는 주제로, 코딩을 몰라도 AI 도구만으로 실행 가능한 5가지 부수입 전략을 다루는
실전 가이드 전자책입니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `ebook.md` | 전자책 원문 (마크다운) |
| `ai-side-income-ebook.pdf` | 판매용 PDF (Gumroad 업로드용) |
| `gumroad-cover.png` | 상품 썸네일 이미지 |
| `gumroad-listing.md` | Gumroad 등록 폼에 그대로 붙여넣을 상품명/설명/가격/태그 |

## 다음 단계 (사용자가 직접 해야 하는 부분)

결제를 실제로 받으려면 본인 명의의 결제 계정 연동이 필요해 여기서부터는 직접
진행이 필요합니다. `gumroad-listing.md`의 "출시 후 체크리스트"를 따라가면 됩니다.

1. https://gumroad.com 계정 생성 (이메일 인증 + 결제 수단 연결)
2. 새 상품 등록 → `gumroad-listing.md`의 상품명/설명/가격/태그 복사-붙여넣기
3. `ai-side-income-ebook.pdf` 업로드, `gumroad-cover.png`를 썸네일로 설정
4. Publish 후 링크를 오픈채팅방/커뮤니티/지인에게 공유
