# 24시간 수익화 실험: Claude Code 실전 완전정복 (전자책)

"24시간 안에 돈을 벌어와라"는 실험에서 출발한 프로젝트입니다.

## 피벗 이력

1차 시도는 "AI로 부업하기" 일반론 전자책이었으나, 크몽에서 가장 포화된 카테고리에
차별화 없는 상품이라는 판단으로 폐기했습니다 (git 히스토리에 보존됨).

2차 상품은 **"Claude Code 실전 완전정복"** — 이 repo(claude-forge) 자체를 자산으로
활용한 한국어 실전 가이드입니다. 차별화 논리:

- **실물 동봉**: 조언이 아니라 실제 작동하는 설정팩(커맨드 35종, 에이전트 11종,
  훅 15종)을 함께 제공 → 저자 신뢰 문제를 상품 구조로 해결
- **희소성**: 설치법 수준을 넘는 한국어 Claude Code 심화 자료는 아직 드묾
- **수요 성장**: 바이브코딩/AI 코딩 에이전트 수요가 급증 중인 시기

2판(현재)에서는 전 챕터를 가상 2인 개발팀 "리프오더"의 실전 적용기로 관통시키고,
터미널 세션 장면 재현, before/after 지표 카드, 클릭형 목차, 페이지 번호 등
출판물 수준의 편집을 적용했습니다.

| 파일 | 설명 |

| `ebook.md` | 전자책 원문 (마크다운) |

| `kmong-listing.md` | 크몽 등록용 서비스명/카테고리/패키지/가격/태그/FAQ |
| `kmong-thumbnail.png` | 크몽 대표 이미지 (4:3, 652x488 규격) |

## 패키지 설계 (요약)

- STANDARD 14,900원: PDF + 치트시트
- DELUXE 19,900원: + 설정팩 zip
- PREMIUM 29,900원: + 30일 내 질문 1회 답변

설정팩은 MIT 오픈소스이므로, 리스팅에 "구매 대상은 팩 자체가 아니라 한국어
가이드+큐레이션"이라는 투명성 고지를 포함했습니다.

## 다음 단계 (사용자 직접 진행)

   [크몽 고객센터](https://support.kmong.com)에 먼저 문의 권장

3. 승인 후 개발자 커뮤니티(OKKY, 커리어리, 관련 오픈채팅/디스코드)에 공유
4. 첫 리뷰 확보 → 가격 인상 검토
