# 24시간 수익화 실험: AI 부수입 전자책

"24시간 안에 돈을 벌어와라"는 실험 미션에서 출발한 결과물입니다. 실제 결제/입금까지는
자동으로 처리할 수 없어(계좌·본인인증 정보가 필요), **24시간 안에 판매 개시가 가능한
상태**로 결과물을 준비하는 것을 목표로 삼았습니다.

판매 채널은 처음에 Gumroad로 준비했다가, 해외 결제 계정 연동이 부담스러워
**크몽(Kmong)** 등록 기준으로 다시 정리했습니다. 두 채널 자료 모두 남겨뒀으니
편한 쪽을 선택하면 됩니다.

## 무엇을 만들었나

주제: "AI로 부업/수익화하기" — 이 repo(claude-forge, Claude Code 프레임워크)와 맞닿아
있는 주제로, 코딩을 몰라도 AI 도구만으로 실행 가능한 5가지 부수입 전략을 다루는
실전 가이드 전자책 + 보너스 워크북입니다.

## 다음 단계 — 크몽 등록 (권장 경로)

1. ⚠️ **먼저 확인**: 크몽은 서비스 등록 전 전문가 인증(본인인증)이 필요합니다. 보통
   한국 통신사 휴대폰 인증 기준이라, 외국인의 경우 대체 인증(외국인등록증 등) 지원
   여부를 [크몽 고객센터](https://support.kmong.com)에 가입 전 문의해보는 걸 권장합니다.
2. 전문가 인증 + 프로필 등록 완료
3. 판매 관리 → 내 서비스 → 판매 시작하기 → `kmong-listing.md` 내용 그대로 복사-붙여넣기
4. `ai-side-income-ebook.pdf`, `bonus-checklist.pdf`, `bonus-30day-planner.pdf`를
   패키지별로 업로드, `kmong-thumbnail.png`를 대표 이미지로 설정
5. 제출 → 심사(영업일 기준 3~5일) → 승인 후 링크를 지인/커뮤니티에 공유

인증이 막히면 `gumroad-listing.md` 쪽 자료로 전환하는 것도 대안입니다 (국제 결제
계정만 있으면 심사 없이 즉시 판매 개시 가능).
